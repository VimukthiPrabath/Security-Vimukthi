A cyberpunk-themed, interactive portfolio website showcasing defensive cybersecurity skills, verified certificates (Google Cybersecurity, AWS, AI), practical hands-on security labs, and an interactive CLI terminal emulator.

---

## 🌟 Key Features

- **Interactive CLI Terminal**: Terminal emulator with security command suite (`help`, `certs`, `skills`, `projects`, `scan`, `about`, `thm`, `whoami`, etc.).
- **Live Matrix Canvas Stream**: Lightweight Matrix stream background on HTML5 canvas.
- **Verified Credentials**: Showcases Google Cybersecurity courses, AWS Cloud Technical Essentials, Google AI Essentials, and Credly badges.
- **Defensive Security Focus**: Highlighting Blue Team operations, SOC analysis, network defense, Linux hardening, and cloud security.
- **Responsive & Modern**: Optimized for desktop, tablet, and mobile browsers with glowing neon cyan/green accents.

---

## 🚀 Live Demo / Local Setup

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/VimukthiPrabath/Security-Vimukthi.git
cd Security-Vimukthi
# Open index.html directly or serve with any static server:
# e.g., using Python:
python -m http.server 8000
```
